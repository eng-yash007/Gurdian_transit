# Computer Vision & AI Modules

This directory contains standalone, decoupled Computer Vision pipelines for face detection, quality analysis, and embedding generation.

- `face_detection/`: Pretrained multi-angle face detection models and frame preprocessing.
- `face_recognition/`: Face alignment and embedding generation.
- `embeddings/`: Vector similarity scoring and matching utilities.
- `models/`: Pretrained model artifacts and weights.
- `tests/`: AI unit and accuracy tests.
