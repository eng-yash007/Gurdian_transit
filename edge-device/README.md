# Edge Device & Hardware Integration

This directory contains drivers, daemon scripts, and simulators for on-bus IoT hardware (Raspberry Pi / Jetson-class systems):

- `camera/`: Video stream capture and local frame sampling.
- `gps/`: NMEA / GPS receiver communication daemon.
- `nfc/`: Optional RFID / NFC backup badge reader daemon.
- `communication/`: Secure API / WebSocket uplink to the backend.
